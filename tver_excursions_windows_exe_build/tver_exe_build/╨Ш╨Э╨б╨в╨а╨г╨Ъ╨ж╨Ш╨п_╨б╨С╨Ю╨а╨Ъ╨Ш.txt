ТВЕРЬ.ГИД — сборка автономного EXE для Windows 10

Важно: после сборки TverGuide.exe запускается на компьютере без установленного Python и без интернета.
Для ОДНОКРАТНОЙ сборки нужен интернет и GitHub Actions (облачный компьютер GitHub соберёт EXE за вас).

1. Создайте бесплатный аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый репозиторий (можно Private — если доступно в вашем аккаунте).
3. Загрузите в репозиторий ВСЕ файлы и папки из этого архива, включая скрытую папку .github.
   На GitHub: Add file -> Upload files. Если .github не получается загрузить через сайт,
   используйте загрузку через GitHub Desktop или попросите помочь взрослого.
4. Откройте вкладку Actions в репозитории.
5. Выберите workflow "Build Windows EXE" и нажмите Run workflow.
6. Дождитесь зелёной галочки. Откройте завершённый запуск, прокрутите вниз до Artifacts.
7. Скачайте TverGuide-Windows10.zip и распакуйте его. Внутри будет TverGuide.exe.
8. Перенесите TverGuide.exe на нужный компьютер Windows 10 и запустите двойным нажатием.
   Интернет для работы сайта после этого не нужен.

При запуске откроется браузер на http://127.0.0.1:5000. Чёрное окно нужно оставить открытым,
пока пользуетесь сайтом. Для остановки нажмите Ctrl+C в этом окне или закройте его.

База пользователей и избранного сохраняется в %LOCALAPPDATA%\TverGuide и переживает перезапуск EXE.
Администратор по умолчанию:
Почта: admin@tver-tour.local
Пароль: Admin123!Change
После первого входа поменяйте пароль, если соответствующая функция предусмотрена проектом.

Примечание: SmartScreen Windows может показать предупреждение, потому что EXE не подписан сертификатом.
Скачивайте и запускайте только файл, собранный из вашего собственного репозитория.
