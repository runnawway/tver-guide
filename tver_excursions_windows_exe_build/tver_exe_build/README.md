# Тверь.Гид — сайт городских экскурсий

Учебный веб-проект на Flask + SQLite. Реализованы регистрация, вход, выход, CAPTCHA, серверная проверка форм, CSRF, защита заголовками, ограничение попыток входа, роли и админ-панель, избранное с сохранением в БД, поиск, карточки экскурсий и JSON API.

## Запуск

Требуется Python 3.10+.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

pip install -r requirements.txt
python app.py
```

Откройте http://127.0.0.1:5000

При первом запуске автоматически создаётся база `tver_excursions.db` и администратор:

- Почта: `admin@tver-tour.local`
- Пароль: `Admin123!Change`

Смените пароль администратора и задайте `SECRET_KEY` / `ADMIN_PASSWORD` через переменные окружения перед публикацией сайта. Это демонстрационные локальные учётные данные, не использовать на реальном публичном сервере.

## Проверяемые адреса

- `/` — главная и каталог из 16 экскурсий
- `/register` — регистрация, проверка email и сложности пароля, арифметическая CAPTCHA
- `/login` — вход (пароль отправляется только POST)
- `/logout` — выход (POST + CSRF)
- `/favorites` — защищённая страница избранного
- `/favorite/<id>` — добавление/удаление (POST + CSRF)
- `/search?q=...` — поиск
- `/excursion/<id>` — подробности экскурсии
- `/admin` — панель администратора
- `/admin/user/<id>/role` — изменение роли (POST + CSRF)
- `/admin/user/<id>/delete` — удаление (POST + CSRF)
- `/api/excursions` — JSON-список экскурсий
- неизвестный URL возвращает HTTP 404

## Безопасность

Пароли хешируются Werkzeug; сервер проверяет email и сложность пароля; CSRF-токен обязателен для всех POST-форм; шаблоны Jinja автоматически экранируют пользовательский ввод; сессия использует HttpOnly и SameSite=Lax; добавлены CSP, X-Frame-Options, X-Content-Type-Options, Referrer-Policy и Permissions-Policy. Ограничение входа — до 5 неудачных попыток с одного IP за 5 минут в рамках одного процесса приложения.

Для production следует использовать HTTPS, постоянный `SECRET_KEY`, `COOKIE_SECURE=1`, серверный rate limiter/хранилище лимитов и WSGI-сервер. CAPTCHA здесь арифметическая, без внешнего сервиса.
